An [AzerothCore](https://www.azerothcore.org/) (WotLK 3.3.5a) module that introduces **Flight Path Discovery Boards** near flight masters, allowing players to permanently unlock neighboring flight paths by purchasing them with gold instead of traveling to each location first. Features **faction-specific flight paths**, configurable destination prices based on zone level, and separate discovery networks for Kalimdor and Eastern Kingdoms. Preserves traditional flight travel, including boats and zeppelins between continents, while reducing the grind of discovering flight paths. No character database modifications required.
